## Lancement du projet

Ce projet utilise Next.js

Pour lancer le site sur un ordinateur :

1. Télécharger le projet depuis GitHub.
2. Installer les dépendances avec `npm install`.
3. Démarrer le serveur avec `npm run dev`.
4. Ouvrir http://localhost:3000 dans un navigateur
